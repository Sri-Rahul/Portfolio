# Sri Rahul Namana's Portfolio

A single-page portfolio designed as a conductor's full score: AI orchestration
made literal. Every part in the score is one of the systems I built or the team
I led, set on manuscript paper in engraving ink with one blue pencil for actions
and the current place.

- **Landing:** my name as the score's title; a Three.js conductor's view whose
  orchestra sections are the systems I built and led (point at a section to cue
  it); and a six-part score of my whole profile, 2022 to 2026, that a pencil
  playhead performs on load, ending on 99% circled.
- **About:** three words played as three gestures (a chord, a held rest, an
  ostinato), with the key facts marked in pencil.
- **Practices:** each practice is a staff with the skills sung as lyrics, and it
  plays its own tune while on screen.
- **Career:** six roles as rehearsal marks, each with a short tune on its staff,
  ending on a final barline in Sep 2026.
- **Work:** four projects as score pages that turn on a pinned stand.
- **Certifications:** a credit line that runs with your scroll.
- **Contact:** the closing phrase, with the headline sung as lyrics.

All motion comes from the score itself (staves drawing, notes struck, marks
stamped, a playhead reading) and switches off under reduced motion.

## Stack

- **React 18** production builds, loaded from a CDN. The JSX is precompiled to plain JS (see Build below), so the browser does no compile work at runtime
- **Three.js** for the conductor's view on the landing
- **GSAP and ScrollTrigger** for the pinned Work stand and scroll-linked states
- **Lenis** for smooth scrolling
- Plain **CSS**; type is Schibsted Grotesk and Old Standard TT, with the treble clef from a one-glyph Noto Music subset
- Staves, notes, barlines and the fermata are drawn as inline SVG
- Project images served as **WebP** with a PNG fallback via `<picture>`

## Run locally

The site ships precompiled, so it runs as static files. Serve the folder over
HTTP (the browser fetches local scripts, so `file://` won't work):

```bash
# any static server, e.g.
npx serve .
# or
python -m http.server 8000
```

Then open the printed URL.

## Build

`app.js` is generated from `app.jsx`. After editing `app.jsx`, recompile:

```bash
npm install --no-save @babel/standalone
node build.js
```

This rewrites `app.js` using the same Babel setup the site used to run in the
browser, so the output is identical to the old in-browser behaviour.

## Structure

```
index.html        entry point, fonts, and the design direction note
styles.css        the whole visual system
app.jsx           React app source: data, sections, components
app.js            precompiled app (generated by build.js)
build.js          JSX precompile script
three-scene.js    the conductor's view (3D orchestra of systems) on the landing
PRODUCT.md        who the site is for and the facts it may use
projects/         project images (.webp + .png fallback)
clients/          client logos (.webp + .png fallback); volza-on-light for the paper ground
```
