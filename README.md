# Sri Rahul Namana's Portfolio

A single-page interactive portfolio: dark, cinematic, with a full-bleed Three.js
landing scene, GSAP scroll animations, Lenis smooth scrolling, and a custom blob
cursor.

## Stack

- **React 18** production builds, loaded from a CDN. The JSX is precompiled to plain JS (see Build below), so the browser does no compile work at runtime
- **Three.js** for the landing icosahedron and orbiter scene, plus the constellation backdrop
- **GSAP and ScrollTrigger** for the scroll-driven reveals and the pinned horizontal Work rail
- **Lenis** for smooth scrolling
- Plain **CSS** with the Geist and Geist Mono typefaces
- Project screenshots served as **WebP** with a PNG fallback via `<picture>`

## Sections

Landing · About · Practices · Career · Work (recent builds) · Certifications · Contact

## Run locally

The site ships precompiled, so it runs as static files. Serve the folder over
HTTP (the browser fetches local scripts, so `file://` won't work):

```bash
# any static server, e.g.
npx serve .
# or
python -m http.server 8000
```

Then open the printed URL.

## Build

`app.js` and `tweaks-panel.js` are generated from the matching `.jsx` sources.
After editing either `.jsx` file, recompile:

```bash
npm install --no-save @babel/standalone
node build.js
```

This rewrites the `.js` files using the same Babel setup the site used to run in
the browser, so the output is identical to the old in-browser behaviour.

## Structure

```
index.html        entry point, loads styles and scripts
styles.css        all styling and animations
app.jsx           React app source: data, sections, components
app.js            precompiled app (generated by build.js)
tweaks-panel.jsx  live theme/motion controls (source)
tweaks-panel.js   precompiled (generated by build.js)
build.js          JSX precompile script
three-scene.js    landing 3D scene
tech-bg.js        constellation backdrop
projects/         project screenshots (.webp + .png fallback)
```
